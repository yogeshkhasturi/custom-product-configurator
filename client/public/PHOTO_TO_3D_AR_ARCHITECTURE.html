1. Executive Summary

This document outlines the architecture for an end-to-end Photo-to-3D Model Generation and AR Ecosystem. It enables any e-commerce or web platform (Shopify, WordPress, Next.js, React, or custom apps) to:

  • Take a single 2D product photo and convert it into a production-ready 3D model (.glb / .usdz) in 10–15 seconds via AI.
  • Calibrate real-world metric dimensions (1:1 scale) so the product appears true-to-size in Augmented Reality.
  • Embed a standalone, framework-agnostic 3D & AR Viewer widget (<universal-ar-viewer>) into any website using just 2 lines of code.
Key Advantage: By decoupling the AI 3D generator (backend) from the AR Viewer (frontend component), this library can be used for any product category: furniture, lighting, home decor, electronics, or fashion accessories.

4. Backend API Implementation (Node.js / Next.js)

This backend endpoint receives the product photo, requests the 3D model from the AI service, and returns the finished .glb URL:

// api/photo-to-3d.js
import axios from 'axios';

const TRIPO_API_KEY = process.env.TRIPO_API_KEY;
const TRIPO_BASE_URL = 'https://api.tripo3d.ai/v2/openapi';

export async function generate3DFromImage(imageBase64, imageFormat = 'jpg') {
  // Step 1: Submit generation task
  const startResponse = await axios.post(
    `${TRIPO_BASE_URL}/task`,
    {
      type: 'image_to_model',
      file: { type: imageFormat, data: imageBase64 }
    },
    {
      headers: {
        Authorization: `Bearer ${TRIPO_API_KEY}`,
        'Content-Type': 'application/json'
      }
    }
  );

  const taskId = startResponse.data.data.task_id;

  // Step 2: Poll status until complete (~10 to 15s)
  let status = 'queued';
  let modelOutput = null;

  while (status === 'queued' || status === 'running') {
    await new Promise((resolve) => setTimeout(resolve, 2000));

    const check = await axios.get(`${TRIPO_BASE_URL}/task/${taskId}`, {
      headers: { Authorization: `Bearer ${TRIPO_API_KEY}` }
    });

    status = check.data.data.status;
    if (status === 'success') {
      modelOutput = check.data.data.output;
      break;
    } else if (status === 'failed') {
      throw new Error('AI generation failed: ' + check.data.data.message);
    }
  }

  return {
    taskId,
    glbUrl: modelOutput.model, // Direct link to .glb model
    renderedPreview: modelOutput.rendered_image
  };
}

5. Metric Scale Calibration for True-to-Life AR

To ensure products render in AR at real-life dimensions (e.g., exactly 0.85m tall), apply this bounding box normalization in Three.js:

import * as THREE from 'three';

export function calibrateModelScale(gltfScene, targetHeightMeters = 0.5) {
  const box = new THREE.Box3().setFromObject(gltfScene);
  const size = new THREE.Vector3();
  box.getSize(size);

  const currentHeight = size.y;
  if (currentHeight > 0) {
    const scaleFactor = targetHeightMeters / currentHeight;
    gltfScene.scale.set(scaleFactor, scaleFactor, scaleFactor);
  }

  // Position the model origin directly on the floor (y = 0)
  const updatedBox = new THREE.Box3().setFromObject(gltfScene);
  const center = new THREE.Vector3();
  updatedBox.getCenter(center);
  gltfScene.position.x -= center.x;
  gltfScene.position.z -= center.z;
  gltfScene.position.y -= updatedBox.min.y;
}

7. CORS & Server Checklist

  • CORS: Ensure your CDN (S3/Cloudflare R2) returns Access-Control-Allow-Origin: * so cross-origin sites can load the 3D assets.
  • MIME Types: Serve .glb as model/gltf-binary and .usdz as model/vnd.usdz+zip.
  • HTTPS: Mandatory for WebXR, Apple QuickLook, and Google Scene Viewer.
